# Нейроагенты

Набор скиллов для Claude Code — четыре агента, закрывающих цикл создания контента для Telegram: от исследования темы до готового поста, видео и бота.

## Агенты

| Агент | Папка | Что делает |
|-------|-------|------------|
| Нейроресерчер | [`skills/ресерчер`](skills/ресерчер/SKILL.md) | Глубоко исследует тему, нишу, конкурентов или аудиторию, проверяет факты и выдаёт отчёт со ссылками |
| Нейрокопирайтер | [`skills/копирайтер`](skills/копирайтер/SKILL.md) | Пишет посты для Telegram-канала голосом автора, вычищает AI-штампы |
| Нейромонтажёр | [`skills/монтажер`](skills/монтажер/SKILL.md) | Режет длинное видео на короткие вертикальные ролики с субтитрами для Shorts/Reels/TikTok |
| Нейротехспец | [`skills/техспец`](skills/техспец/SKILL.md) | Собирает рабочего Telegram-бота с кнопками, лид-магнитом, сбором заявок и ИИ-ответами |

## Как это работает вместе

Типичный порядок: **ресерчер** собирает отчёт по теме/нише → **копирайтер** пишет пост или **монтажёр** режет клипы на основе отчёта → **техспец** собирает бота, который всё это раздаёт аудитории.

Каждый агент — это отдельный `SKILL.md` в формате Claude Skills с описанием, по которому Claude сам понимает, когда его подключить.
