# 5 нейроагентов для Claude Code

Пять готовых агентов, которые работают внутри Claude Code:

| Агент | Команда | Что делает |
|-------|---------|-----------|
| 🔍 Ресерчер | `/ресерчер` | Исследует нишу и конкурентов со ссылками на источники |
| ✍️ Копирайтер | `/копирайтер` | Пишет посты твоим голосом, а не как нейросеть |
| 🎬 Монтажёр | `/монтажер` | Режет длинное видео на вертикальные клипы с субтитрами |
| 🤖 Техспец | `/техспец` | Собирает работающего Telegram-бота |
| 🎨 Дизайнер | `/дизайнер` | Собирает лендинг одним HTML-файлом |

## Установка

### Шаг 1. Поставь Claude Code

Нужен Node.js 18+. Открой терминал и выполни:

```bash
npm install -g @anthropic-ai/claude-code
```

Проверь: `claude --version`

### Шаг 2. Поставь агентов

Из корня склонированного репозитория:

```bash
bash install.sh
```

Или вручную — просто скопируй папки:

```bash
mkdir -p ~/.claude/skills
cp -r skills/монтажер skills/копирайтер skills/техспец skills/дизайнер skills/ресерчер ~/.claude/skills/
```

### Шаг 3. Проверь

Запусти Claude Code в любой папке:

```bash
claude
```

Набери `/` — в списке появятся все пять агентов.

## Как пользоваться

Можно вызвать напрямую командой:

```
/дизайнер сделай лендинг под курс по фотографии
```

А можно просто написать задачу человеческим языком — Claude сам подберёт нужного агента:

```
Нарежь мне шортсов из этого видео: video.mp4
```

## Что нужно для отдельных агентов

Ставится один раз, только если будешь пользоваться:

- **Монтажёр:** `ffmpeg` + `pip install openai-whisper yt-dlp`
- **Техспец:** `pip install python-telegram-bot python-dotenv` + токен от [@BotFather](https://t.me/BotFather)
- **Копирайтер, дизайнер, ресерчер:** ничего не нужно

Не знаешь, как поставить — просто скажи об этом Claude Code, он поставит сам.

## Частые вопросы

**Команда `/монтажер` не появилась**
Перезапусти Claude Code. Проверь, что папка на месте: `ls ~/.claude/skills/`

**Пишу `/монтажёр` через «ё» — не находит**
Команды без буквы «ё»: `/монтажер`.

**Можно ли менять эти файлы под себя?**
Нужно. Открой `SKILL.md` и правь — это обычный текст. Агенты станут точнее под твои задачи.

## Как агенты работают вместе

Типичный порядок: **ресерчер** собирает отчёт по теме/нише → **копирайтер** пишет пост, **монтажёр** режет клипы, **дизайнер** собирает лендинг на основе отчёта → **техспец** собирает бота, который всё это раздаёт аудитории.

Каждый агент — это отдельный `SKILL.md` в формате Claude Skills с описанием, по которому Claude сам понимает, когда его подключить.
