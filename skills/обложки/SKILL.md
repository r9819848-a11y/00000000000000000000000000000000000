# Нейрообложечник

Собирает превью, ради которого палец останавливается в ленте. Обложка и заголовок продают клик, само видео — обещание уже выполняет.

## Железное правило

**Обложка живёт в мелком размере рядом с чужими обложками — не в полный экран сама по себе.** Всё, что не читается за 1 секунду при ширине ~120px, не работает. Проверяй именно так, а не увеличенной картинкой во весь монитор.

## Шаг 1. Спроси, если непонятно

1. **О чём видео и в чём его обещание?** Одна фраза — та же суть, что и в заголовке.
2. **Кто уже снял обложки в этой нише хорошо?** Посмотри 3–5 чужих превью в выдаче рядом — с чем будет конкурировать эта обложка.
3. **Есть кадр или фото автора?** Лицо с эмоцией почти всегда сильнее абстрактной картинки — если фото нет, спроси, можно ли снять или взять кадр из видео.
4. **Уже есть фирменный стиль канала** (цвета, шрифт, рамка)? Не изобретай новый стиль на каждое видео — обложки одного канала должны узнаваться в упор друг рядом с другом.

## Шаг 2. Что должно быть на обложке

Работающая формула для длинных роликов:

```
ЛИЦО/ОБЪЕКТ  — крупно, с явной эмоцией (удивление, шок, решимость) или конкретный предмет по теме
ТЕКСТ        — 3–5 слов максимум, крупно, контрастно
АКЦЕНТ       — стрелка, обводка, цифра — то, что ведёт взгляд к сути
```

Текст на обложке **не повторяет заголовок дословно** — он дополняет его недостающей деталью или эмоцией. Заголовок объясняет, обложка — интригует.

Хорошо:
- Заголовок: «Доходность пулов Uniswap: сколько я реально заработал»
- Текст на обложке: «+340% ИЛИ -100%?» — конкретика, которой нет в заголовке

Плохо:
- Обложка повторяет заголовок слово в слово — тогда один из двух элементов лишний
- Обложка — скриншот интерфейса без текста и эмоции — тонет в ленте, где у всех такие же скриншоты

## Шаг 3. Правила читаемости

1. **Максимум 3-4 цвета.** Фон, текст, акцент, тень — и всё.
2. **Контраст текста и фона — не меньше, чем чёрный на белом.** Полутона на мелком экране не читаются.
3. **Обводка или тень у текста**, если фон не однородный — иначе буквы сливаются с картинкой.
4. **Один шрифт, жирное начертание.** Тонкие шрифты пропадают при уменьшении.
5. **Не больше одного лица крупным планом.** Два лица одинакового размера — взгляд не знает, куда смотреть.
6. **Не громозди рамками с четырёх сторон.** Рамка нужна только если это фирменный стиль канала, а не украшение.

## Шаг 4. Проверка на кликабельность

Перед сдачей:

- [ ] Уменьши превью до размера как в мобильной ленте (~120×68px) — текст ещё читается?
- [ ] Поставь обложку рядом с 3-5 чужими из этой ниши (скриншот выдачи) — она выделяется или тонет?
- [ ] Есть ли на ней то, чего нет у конкурентов — эмоция, цифра, ракурс?
- [ ] Текст на обложке говорит что-то новое, а не дублирует заголовок?
- [ ] Если убрать текст — понятно ли по одной картинке, о чём видео?

Не решай в одиночку — покажи автору 2–3 варианта и дай выбрать, как в любом другом контентном скилле.

## Технический способ собрать обложку

Если делаешь HTML/SVG-макет (быстро, без Photoshop):

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<style>
  body { margin:0; }
  .thumb {
    width: 1280px; height: 720px;
    position: relative;
    overflow: hidden;
    background: #0b0f1a; /* фон под фирменный стиль канала */
    font-family: Arial, sans-serif;
  }
  .thumb img.photo {
    position:absolute; right:0; bottom:0; height:100%;
  }
  .thumb .text {
    position:absolute; left:60px; top:80px;
    max-width: 700px;
    font-size: 110px;
    font-weight: 900;
    color: #fff;
    line-height: 1.05;
    text-shadow: 6px 6px 0 #000;
  }
  .thumb .accent {
    color: #ffcc00; /* акцентный цвет фразы/цифры */
  }
</style>
</head>
<body>
  <div class="thumb">
    <div class="text">+340% <span class="accent">ИЛИ</span> -100%?</div>
    <img class="photo" src="face.png" alt="">
  </div>
</body>
</html>
```

Открой в браузере на 1280×720, сделай скриншот именно этой области — это и есть готовый thumbnail (YouTube принимает JPG/PNG 1280×720, до 2МБ).

Если нужен рисунок или фото, которого нет — предупреди, что сгенерированное лицо/фото может выглядеть неестественно, и предложи взять кадр из самого видео вместо генерации с нуля.

## Принципы

1. **Проверяй в мелком размере.** Красиво увеличенным — не значит кликабельно в ленте.
2. **Обложка дополняет заголовок, а не повторяет.**
3. **Один фирменный стиль на весь канал.** Не изобретай заново для каждого видео.
4. **Эмоция сильнее интерьера.** Лицо с реакцией почти всегда выигрывает у абстрактной картинки.
5. **Показывай варианты.** Финальное решение — за автором канала.
